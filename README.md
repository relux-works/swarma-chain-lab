# swarma-chain-lab

Experiments on anchoring Swarma identities and grants on a public chain, starting with Namecoin. This is a laboratory: results here are research evidence, not a product, a release or a production qualification. Each experiment lives in its own directory under `experiments/` and states what it ran on and what it does not prove.

No experiment uses real coins or owner keys unless its README says so.
