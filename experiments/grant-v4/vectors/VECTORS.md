# B1n primitive and stated-fact vectors

**no valid swarma-grant/4 vectors until B0**

This is the narrowed B1n unit. `vectors.json` is generated by the laboratory Go
APIs, then independently re-derived by Python. An `ok` result means that the
named primitive or stated-fact predicate succeeded. It never admits a grant.
There are 237 cases: 78 successful primitive/stated-fact cases and 159 refusals,
covering all 27 first-refusal codes in LIP-0020 §9 and `wire/errors.go`.

Canonical document encoding is exercised on the complete assent and unsigned
preparation schemas and on the restricted generic document grammar of W1.
Registry arithmetic covers all seven entries, including type-only arithmetic
inputs for the five memberless types. Those bytes are **not valid objects**.
Every registry digest is signed with each of public test scalars 1, 2 and 3,
using exactly 32 zero bytes for `aux_rand`. The three complete assent payloads
also have independently re-derived signatures. A mechanical signature over the
issuance registry digest does not create a signed issuance protocol object:
W8's preparation remains unsigned.

`CheckIssuance` inputs are labelled `stated_grant_facts` and `stated_evidence`.
They are a test transport for Go inputs, **not authenticated grant bytes**, a
presentation format or a proposed grant schema. In particular the strings
standing for grant ID, signature and content address are supplied facts. This
unit cannot establish their provenance. Conditional success yields only the
specified preparation and its commitment. W9.4 step 1 remains unavailable.

## Format and checking

The root format is `swarma-lab-primitives/1`, with the immutable specification
revision, public test scalar inventory, fixed auxiliary randomness and an
ordered `vectors` list. Each vector has:

| Field | Meaning |
| --- | --- |
| `id` | Stable unique case name. |
| `purpose` | Specific primitive claim or refusal exercised. |
| `spec` | LIP-0020 rules/sections; additional upstream references where needed. |
| `operation` | Laboratory API adapter selected by the fixture, never by a grant. |
| `input` | Fully stated test inputs. `*_hex` values are exact octets in lowercase hex. Context/fact objects use Go's exported field names solely as fixture transport. `bound` strings preserve full uint64 values in generic readers. |
| `output` | Recomputed outputs and the exact first-refusal `code`; `ok` for success. Refusal has no output object bytes. No timestamp or host identity enters generation. |

`Generate` invokes the exported lab APIs and checks refusal results against
explicit expectations fixed in the generator from the cited rules. An unexpected
code aborts generation as a `FINDING`. The Go drift test compares regenerated
JSON **byte for byte**, including ordering, spacing and final newline.

The Python implementation imports only the standard library, runs under
`python3 -I`, does not execute Go, and reads no Go source or generated Go result
stream. It independently implements restricted canonical encoding, exact integer
parsing, ordered refusals, BIP340, consent bytes/IDs and the stated-fact issuance
pipeline. It recomputes every output field and compares the complete output
mapping, including absent fields on refusal. It reports each disagreement as a
`FINDING` with the vector's spec citation; exit 1 means disagreement, exit 2 means
a setup/format/control error, and exit 0 means full agreement. A finding must be
reported, never fixed by adjusting a vector toward Go.

BIP340 is derived from [BIP340 Specification, Default Signing and Verification](https://github.com/bitcoin/bips/blob/2885f13d3f37890e328683166dbcbc60b488d13a/bip-0340.mediawiki).
Python uses its own affine secp256k1 group arithmetic, even-Y `lift_x`, tagged
nonce/challenge derivation and `sG-eP` verification. Its external calibration is
published [test vector 0](https://github.com/bitcoin/bips/blob/2885f13d3f37890e328683166dbcbc60b488d13a/bip-0340/test-vectors.csv),
plus an altered-message negative control. Verification-only rows 0–14 additionally
cover valid high-s signatures, odd-Y, infinity, non-curve points and r/s bounds;
only their public key, message, signature and expected verdict are imported.
The signer accepts only the three public test scalars. This variable-time test
implementation is not a signer for real keys.

Consent inherits timestamp range 1–253402300799 and fixed member order from
[LIP-0013 §3.1](https://github.com/relux-works/swarma-link-spec/blob/bd3bc80e5543d8a563343ec05abd1a5f3f67284c/lips/LIP-0013-trust-contract.md#31-event),
as LIP-0020 W7.3 requires. Consent signatures cover the NIP-01 event ID,
not a registry typed digest.

| Contract | Accepted boundary / nearest control | Refused neighbour |
| --- | --- | --- |
| W1 byte limits | Generic canonical documents at 1024 and 2048 bytes | 1025 and 2049: `WIRE_SIZE`. These are caller-limit tests, not fabricated maximum-size schema-valid assents/preparations. Their closed schemas cannot be padded with arbitrary members. |
| W1 depth | 16 container levels, root counted | 17: `WIRE_SIZE`; competing truncation, syntax and UTF-8 defects exercise earliest-byte precedence. |
| W2 number form | 9007199254740991 | +1: `WIRE_NUMBER`. |

| W5 r/s ranges | r=p−1 and s=n−1 pass range preflight | r=p,p+1 and s=n,n+1: `WIRE_SIGNATURE`. Passing preflight is not passing verification. |
| W3 signing key | Valid 32-byte x-only keys | Short/long/uppercase form: `WIRE_MEMBER`; non-point and x=p,p+1: `WIRE_KEY`. |
| W7 consent size | 2048 bytes, extending the specified printable name tag | 2049: `CONSENT_SHAPE`. |
| W7 timestamp | 1 and 253402300799, including ReadConsent | 0 and upper bound+1: `CONSENT_SHAPE`. |
| W7 future time | created_at = supplied now | One second ahead: `CONSENT_TIME`. |
| W7 issuer age | 259200 seconds | 259201: `CONSENT_AGE`; verifier accepts that age. |
| W7 evidence height | height=recent=100 | height=101: `CONSENT_EVIDENCE`. |
| W7 spent evidence | Spent above snapshot at 101 is accepted | Spent at snapshot=100: `CONSENT_EVIDENCE`. |
| W8 outpoint index | 0 and 4294967295 | 4294967296: `WIRE_INTEGER`. |
| W8 frame | 72 bytes, zero value, one OP_RETURN, exact prefix/version/pointer | 71/73 bytes, value=1, count=0/2, changed framing/pointer: `ISSUANCE_FRAME`; one commitment byte changed: `ISSUANCE_COMMITMENT`. |

Categorical refusals have no numeric boundary+1. Their nearest controls are
matching versus mismatching references/bindings/keys, present versus missing
members/evidence/outpoint, supported versus unsupported types, unused versus
consumed IDs, and valid versus invalid signatures. The per-vector inventory below
names the exact witness and code. All 10 pairs of buildable W9.4 steps 2–6 and all
10 pairs of W7.4 steps are exercised, with each individual defect and valid
controls also present. W9.2 compound cases cover whole-document precedence and
earliest syntax/depth/UTF-8 defects.

No live node, ownership/history walk, issuer journal, replay recovery, real grant
admission or delegation/re-delegation is qualified. String-form schema placement,
integer overflow computations and the missing grant/schema bounds remain with
the type specifications: no complete W7/W8 schema has an amount or arithmetic
operation to exercise. Python checks supplied node/clock/consumed facts only,
not their authentication or persistence. No formal surface table was supplied in
the brief; this inventory is the bounded coverage map, not a claim to satisfy an
unprovided attack-surface catalog.

## Tools and commands

Use Go 1.26.10 with `GOTOOLCHAIN=local`, `GOWORK=off`, and task-owned absolute
HOME, config, caches, temporary directory and test checkout. Keep TMPDIR short.
Dependency acquisition precedes `GOPROXY=off` checks. From the repository root:

```sh
go -C experiments/grant-v4/vectors mod download
go -C experiments/grant-v4/vectors mod verify
go -C experiments/grant-v4/vectors run ./cmd/generate > .temp/vectors-regenerated.json
cmp experiments/grant-v4/vectors/vectors.json .temp/vectors-regenerated.json
go -C experiments/grant-v4/wire test -count=1 ./...
go -C experiments/grant-v4/wire vet ./...
go -C experiments/grant-v4/vectors test -count=1 ./...
go -C experiments/grant-v4/vectors vet ./...
go -C experiments/grant-v4/vectors build ./...
python3 -I experiments/grant-v4/vectors/scripts/check-vectors.py
python3 -I .github/scripts/check-public-hygiene.py
python3 -I .scripts/check-module-graph.py
```

`cmd/generate` writes JSON to stdout and errors to stderr; normal validation
never overwrites the checked-in fixture. Logs and controls belong in `.temp/`.
The new internal consumer edge has the public-proxy-resolved wire floor of the
repository's existing module snapshot; `replace ../wire` deliberately exercises
the current laboratory source. The root module inventory records this edge.

To reproduce the one-byte control, copy both sibling `wire` and `vectors`
modules to an isolated test checkout. After green Go and Python controls, change
one ASCII hex digit in the `arithmetic-0` output's `payload_id` in that copied
`vectors.json`. `go test -run '^TestVectorsDrift$' -count=1 ./...` must exit 1 with
`vectors.json drift`, and the independent Python command must exit 1 with
`FINDING arithmetic-0` naming `payload_id`. Check that the plant changes exactly
one byte; restore only that owned copy, then require both green controls again.
This bounds the detectors to an output-byte mutation, not every possible mutant.

## B0 decision list kept from B1

1. Publish/pin a candidate `swarma-grant/4` member schema: required/optional
   members, nested shapes, exact integer and key forms, recipient modes,
   issuer/owner pins, executor, limits, window, recent block and seal.
2. Define J12 group/template/range member names, forms and traversal, and
   the representation of “no certifier” and any group stop coins. Preserve
   J9's semantic restriction; encoding alone must not broaden it.
3. Fix candidate grant size/depth/count limits and refusal precedence/codes
   for those shapes. LIP-0026 §8 R8.4 proposals do not resolve this.
4. Reconcile the lab's unsupported-grant reader with that pinned schema in
   a separately authorized behavior change, or explicitly redefine B1 as
   arithmetic-only primitives with no VALID grant claim. The latter cannot
   satisfy the current brief's grant-document requirement.


The list above is retained as the original B1 schema decision record. The lead
selected its arithmetic-only narrowing for B1n; its last sentence describes the
superseded whole-grant brief, not a remaining blocker of this primitive unit.
B0 still owns the grant member/row schema, key/integer forms, bounds and refusal
precedence. Any future grant reader behavior needs its own authorized change.
