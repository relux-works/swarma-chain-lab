# Remaining qualification

- Legacy omitted-dialect New/CLI exists only for old Messages tests and is
  unqualified for deployment. Deploy requires explicit pinned mode and a public
  model config copy. Config copies must track the proxy; no live metadata endpoint
  or bootstrap codec expansion attests a remote profile.
- Responses mode is a bounded, nonstream, text-only scripted consumer. A Codex
  harness, tools, streaming and a paid provider remain separate qualification.
- The rented-agent runtime, deployment and host containment remain operator
  decisions. This scripted fixture does not install or select them.
- Full composition depends on landed BG1 intake/presentation, RL1 relay/tagged
  helper, and GA1 registrar wiring. Unit integration is not evidence that a real
  booking reached a running payload or that expiry wiped a host slot.
- A macOS rehearsal may inject the actual model Service as the registrar,
  replacing only Linux admin peer transport in harness code. It must name that
  substitution and preserve real accounting, TLS and all other product behavior.
- No paid upstream call, real wallet custody, production Linux helper execution,
  hosted check or deployment is implied by local test success.

- DA1b must define idempotent remote model-result retrieval before an in-flight
  crash can recover its answer; DA1 returns terminal `uncertain` without retry.
- Infra/DK5b must provision the explicit persistent per-slot journal and define
  supervisor restart/retention. No deployed launcher changes are included here.
- Relay acceptance does not prove a third-party renter displayed the reply or
  durably deduplicated its inbox. That endpoint contract remains separate.
